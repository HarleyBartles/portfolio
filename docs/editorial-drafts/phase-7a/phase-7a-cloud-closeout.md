## Settled professional hierarchy

About stops opening with `professional truth`, `evidence in view`, generic
`underspecified, consequential problems`, or `frontier of agentic engineering`
positioning. Current Access work and consequence earn the professional claim instead.

The Access treatment uses representative examples, not an exhaustive win list:

- current end-to-end Access Checks ownership;
- DBS Update and Right to Work Sharecode browser automation with the bounded LLM /
  deterministic execution split;
- `No source capture, no success.` as the memorable production invariant and a
  downstream no-charge consequence;
- the commercial outcome of two additional integrated paid checks;
- the cross-product v1-to-v2 sequencing decision; and
- Recruitment CRM's set-based SQL correction on the CV to widen the evidence beyond the
  two examples discovered in this room.

Barbican/Arch supplies concise provenance for the later rule that architectural
complexity has to earn its place. Brand Addition remains one long progression through
commercial work and team management, culminating in Web Manager for the final couple of
years; it must never read as thirteen years under the Web Manager title.

## Settled visual language

The governing recommendation is **reuse grammar, not layouts**.

The rendered article pull quotes establish a shared site editorial primitive: soft copper
wash, strong copper left rule, oversized italic Fraunces, deliberate whitespace and an
optional Fira Code secondary line when it adds real attribution or classification.

About uses the short-statement form:

> **No source capture, no success.**
>
> `PRODUCTION INVARIANT`

The later site-wide polish pass is responsible for comparing and harmonising recurring
visual language across the complete site, but it should start from the recommendations
recorded by this room rather than rediscovering them from implementation CSS.

Imagery remains a later implementation/polish concern, but this room has supplied its
recommendations: no forced/generated About hero, no fabricated employer UI, no generated
acting history, existing project-native imagery where useful, and an image-free CV.
