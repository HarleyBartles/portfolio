# Phase 7A editorial room

This directory is the durable handoff from the active Phase 7A Cloud design room.
The room began as Professional Outcomes and Proof Compression and expanded on
29 August 2026 into the complete design of the affected professional hiring
surfaces: copy, information architecture, proof routes, styling direction and
site-wide visual-language recommendations.

Use the files by responsibility:

- [`phase-7a-cloud-editorial-brief.md`](./phase-7a-cloud-editorial-brief.md) records the original room brief and source-discovery mandate.
- [`phase-7a-cloud-discovery-record.md`](./phase-7a-cloud-discovery-record.md) owns approved employer-safe source truth, disclosure boundaries and secondary discovery.
- [`phase-7a-about-page-design.md`](./phase-7a-about-page-design.md) owns the final About information order, public copy, links, layout and art direction.
- [`phase-7a-cv-page-design.md`](./phase-7a-cv-page-design.md) owns the final CV information order, two-page copy, screen/print layout and hostile-reader acceptance contract.
- [`phase-7a-site-visual-language-recommendations.md`](./phase-7a-site-visual-language-recommendations.md) owns the visual-language recommendations this room expects Phase 7A and the later site-wide polish pass to consume.

The active Phase 7A specification is the binding phase contract. These room
artifacts supply the material editorial and visual decisions that the
specification delegates to this Cloud room. Local implementation should execute
those decisions rather than redraft them.

Keep private operational detail in the conversation, not this public
repository. Implementation may use only facts Harley has explicitly approved
for publication.
