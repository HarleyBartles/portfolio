# Phase 8P stage 2 — page rhythm and density

**Status:** Settled in PR #46. Stage 2 is closed unless integrated proof exposes a concrete contradiction.

This decision is subordinate to the wider Phase 8P visual-language checkpoint, typography contract and stage-1 evidence-custody decision. It closes the rhythm/density discovery stage without authorizing implementation.

## Selected default: variable cadence

**Space expresses relationship.** Material that belongs to one claim forms a tighter reading cluster. A change of argument, subject or route movement earns more separation.

The system does not use one spacing temperament everywhere. Project/evidence-heavy routes may tighten prose, artifact, qualification and proof when they belong to the same engineering claim, while larger story movements retain clear breathing room. Authored longform keeps a steady reading pulse rather than inheriting project-page compression.

This is a semantic rule, not permission for arbitrary spacing-by-vibe. Local implementation should first ask whether adjacent material is one thought or two; exact spacing values are then implementation/refinement decisions unless they materially alter the character of the system.

## Rules are subordinate to space

Rules may clarify a real boundary, but they are not the default way to manufacture hierarchy.

Use a rule when a boundary needs explicit visual reinforcement. Do not draw a rule merely because more separation is desired. Negative space should carry most large-scale hierarchy so the system does not drift into dossier/admin language.

## Rejected defaults

### Even breathing

One generous spacing temperament across prose, proof and section changes is rejected as the global rule.

It is calm, but it weakens semantic attachment between claim and evidence. Proof begins to feel detached from the statement it supports, and generous whitespace can drift toward generic premium-editorial emptiness.

### Compact record

A higher-density, rule-heavy record treatment is rejected as the global rule.

It can support evidence-heavy project passages, but when applied broadly it makes authored longform feel like an evidence inventory. Frequent rules become the dominant hierarchy mechanism and push the site toward dossier/admin energy.

## Route-family implications

The same visual grammar may express different densities without becoming separate site systems.

- Project/evidence-heavy routes may form compact proof clusters around a claim, then open up between major story movements.
- Authored longform should retain a regular prose pulse and larger argumentative breaks; it should not compress simply because technical pages benefit from denser evidence relationships.
- Professional/heterogeneous routes may vary cadence according to semantic grouping, but should not become a grid of uniformly spaced modules.

Density follows the content relationship, not the route label alone.

## Evidence used for the decision

The deterministic comparison surface `phase-8p-rhythm-density-comparison.html` held typography, cool-mineral substrate, project-colour authority, earned-interruption geometry and artifact-first custody fixed while testing three spacing treatments against materially different source content:

- a Wild Bunch engineering/evidence section drawn from the current case-study source;
- authored longform drawn from the current `Why ADRs?` article.

This pressure test was sufficient because the same spacing rule had to support proof-led technical composition and sustained authored reading without flattening either into the other.

## Deliberate challenge

The selected `variable cadence` direction was challenged on the risk that it could become designer shorthand for arbitrary spacing decisions.

The direction survives only with the semantic guard above: spacing is justified by relationship. One claim and its proof close ranks; a real change of movement opens space. If an implementation decision cannot be explained in those terms, it is not protected by this contract.

## Stage-2 stop decision

The rhythm/density question has crossed the Phase 8P stop rule:

- three materially different treatments were rendered;
- evidence-heavy project material and authored longform were pressure-tested together;
- Harley accepted the variable-cadence baseline;
