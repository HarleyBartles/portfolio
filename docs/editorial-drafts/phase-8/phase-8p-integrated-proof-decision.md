# Phase 8P integrated route proof decision

**Status:** Accepted by Harley on 30 August 2026. Integrated proof is closed. No substantive correction loop was required.

This record closes the final Phase 8P discovery stage. It proves the accepted visual language as one system across materially different non-home route families. It does not prove the later production implementation.

## Proof surface

The deterministic proof is [`phase-8p-integrated-route-proof.html`](./phase-8p-integrated-route-proof.html).

It combines the already-settled typography, cool-mineral substrate, bounded project-colour authority, earned-interruption grid, artifact-first custody, variable cadence and quiet shell. It does not introduce a new component system.

The surface is evidence of coexistence, not a production template.

## Route families

### Project / evidence-heavy

Wild Bunch pressure-tested:

- Source Sans site/project register;
- cool-mineral shared ground;
- bounded warm project-colour bleed;
- earned interruption around real project evidence;
- artifact-first image and technical evidence custody;
- variable cadence between story movement and proof cluster;
- quiet shell with ordinary Projects active state.

The route remains recognisably Wild Bunch without becoming a Western-themed microsite.

### Authored article

`Why ADRs?` pressure-tested:

- Source Serif only where authored reading begins;
- Source Sans shell, metadata and section hierarchy;
- no project-colour atmosphere;
- stable longform reading cadence;
- article display remaining quieter than site/project display;
- ordinary Writing active state.

The article feels like a different content register inside the same site rather than a separate editorial theme.

### Professional / heterogeneous

About pressure-tested:

- Source Sans throughout;
- large site display with professional lede;
- one earned semantic rail for employer/date/scope context;
- technical evidence remaining technical without a universal evidence card;
- ordinary About active state;
- narrow collapse back to semantic source order.

The rail survives because it carries independent contextual information, not because it decorates the composition.

## Shell identity decision

The integrated proof deliberately added visible `Harley Bartles` text beside the HB mark inside the already-accepted quiet shell.

It improved first-visit identity without creating a second masthead row, folio or route-context slot. It remained legible at desktop, narrow and actual 200% browser zoom.

**Accepted:** the quiet shell includes the HB home mark, visible `Harley Bartles`, and the ordinary primary navigation in one flow.

## Desktop and narrow proof

All three route families were inspected in desktop and 390 CSS pixel narrow states.

Observed outcome:

- hierarchy remained clear across unlike content;
- the same shell worked without becoming the visual protagonist;
- project colour remained bounded and the mineral substrate remained dominant;
- desktop rails/asymmetries collapsed into ordinary source order on narrow;
- article reading rhythm remained distinct from evidence-heavy density without becoming a second design system;
- no route required a new visual primitive to remain coherent.

## Actual 200% browser zoom proof

After the normal desktop/narrow pass, Opera was set to actual 200% zoom and all six proof states were inspected again.

No visual-language contradiction was observed:

- no page-level horizontal layout break;
- no clipped or colliding display heading;
- no shell hierarchy failure;
- no evidence collision;
- no route-context furniture appeared as an emergency responsive workaround;
- metadata remained subordinate but legible;
- article display remained quieter than site display;
- About's large heading wrapped aggressively but coherently;
- project bleed remained bounded and subordinate to the mineral ground.

The single permitted substantive correction loop was therefore not invoked.

## Artifact-preparation defect

The proof surface's old Dustwell derivative still includes a small strip of surrounding application surface above the town-hub evidence.

Harley had already clarified that the evidence-bearing region is the town hub itself. This is a specimen crop defect, not a failure of artifact-first custody or integrated composition.

Production may correct the crop or use a better live Wild Bunch capture. Wild Bunch can supply reproducible seeded town-hub variation; capture remains evidence-led and must preserve custody rather than turning into indefinite screenshot hunting.

## AI-convergence valuation gate

The integrated visual system passed the design-room gate.

Its identity is not primarily explained by the 2026 cream/beige + rusty accent + huge Serif + tracked-label + ticker + rounded-component cluster that triggered the Phase 8P re-scope. It also does not depend on faux-handmade anti-AI styling.

The accepted character comes from:

- semantic type roles;
- cool-mineral shared ground;
- project-native bounded colour;
- rectilinear discipline with rare earned interruption;
- source-native evidence custody;
- semantic spacing relationships; and
- a quiet, ordinary navigation shell.

The valuation gate must be rerun against the rendered production implementation because local composition could still turn correct rules into a generic template.

## Acceptance

Harley accepted the integrated system as the Phase 8P visual contract after the desktop/narrow and actual 200% proof.

Phase 8P design discovery is complete.
