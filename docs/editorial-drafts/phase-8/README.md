# Phase 8 preliminary visual-language remediation

This directory is the durable handoff surface for the preliminary phase that now blocks Phase 8 homepage implementation. The immediate job is to audit and redesign the non-home routes into a deliberate, composed visual system before the homepage becomes that system's front matter.

- [`phase-8-cloud-editorial-brief.md`](./phase-8-cloud-editorial-brief.md) is the re-scoped Cloud Sol research and design-room handoff.
- [`phase-8-cloud-decision-record.md`](./phase-8-cloud-decision-record.md) records the valuation rule, protected-default amendment, deferred homepage decisions and planning baton.
- [`phase-8p-typography-contract.md`](./phase-8p-typography-contract.md) fixes the selected Source-family roles, hierarchy tokens, validation rules and licensed font custody.
- [`phase-8p-typography-specimen.html`](./phase-8p-typography-specimen.html) is the internal, deterministic browser proof for that typography contract. It demonstrates typography only and is not a production layout.
- [`phase-8p-typography-skill-tdd.md`](./phase-8p-typography-skill-tdd.md) records the frozen pre-PR pressure tests and the complete-system GREEN evidence.
- [`applying-portfolio-typography`](../../../.agents/skills/applying-portfolio-typography/SKILL.md) routes implementation and review workers through the contract without duplicating it.

The approved homepage specification remains useful deferred input. It is not authority to implement `/` while the preliminary remediation gate is open. Warm paper, copper, large serif typography, tracked labels and repeated rounded-panel furniture are no longer protected defaults merely because previous phases established them.

PR #45 is the completed Phase 8P typography checkpoint and is ready to merge while remaining draft. Typography is settled and implementation-ready as a sub-contract; the temporary three-way selection board is intentionally not retained. Phase 8P itself remains open: broader visual-language research, alternatives and decision dialogue continue in a fresh PR #46. That continuation has not been created by this checkpoint. Merging PR #45 does not authorize implementation, close Phase 8P or unblock the homepage. Public non-home implementation planning remains blocked until Harley accepts the complete wider visual contract; homepage planning remains blocked through Phase 8P completion, implementation, rendered review and acceptance.
