# Phase 8 homepage editorial room

This directory is the durable handoff surface for the Harley-led Cloud chat that settles the homepage's editorial and visual calls before local implementation planning begins.

- [`phase-8-cloud-editorial-brief.md`](./phase-8-cloud-editorial-brief.md) is the opening room contract and read order.
- [`phase-8-cloud-decision-record.md`](./phase-8-cloud-decision-record.md) is the Cloud room's live decision and handoff record.

The approved Phase 8 specification remains the phase contract. The room may recommend an explicit amendment when current evidence exposes a design conflict; it may not silently replace the spec or implement the homepage.

Keep private or merely exploratory material in the conversation. Commit only decisions, public-safe copy candidates, rejected alternatives, evidence and unresolved boundaries that have durable production value.
