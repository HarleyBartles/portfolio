# Phase 8 homepage — Fold 2 Marketplace visual direction

**Status:** Accepted design-room direction on 1 September 2026. This is the current Fold 2 art-direction authority for the Agent Asset Marketplace / Superpowers+ movement. It records the decision path as well as the settled brief so later local planning can recover why the shape language exists.

This is a forward authority record. It does not rewrite earlier exploratory proofs or pretend the route here was cleaner than it was.

## Fold 2 job: convert attention into interest

Fold 1 owns the five-second decision space and is now locked separately. Its job is to earn attention.

Fold 2 gets approximately **ten seconds from the point it settles into view** to prove that attention was worth spending. It is deliberately denser than Fold 1. The expected read is not a long case-study read: the visitor should take the composition in once, read it once, and decide whether to spend a larger click/scroll on the deeper work.

The desired timing is approximately:

- first ~2 seconds: `this looks good; it feels premium and belongs on this homepage`;
- next ~3–5 seconds: `wait — I can see what this visual is actually showing`;
- remaining seconds: headline/copy/composition close the inference and offer the deeper route.

If Fold 2 has not earned interest inside that window, Fold 1's attention has been squandered.

The movement therefore must not behave like a conventional portfolio teaser made from explanatory prose beside a framed screenshot. The reader has already accepted `See the work ↓`; Fold 2 should reward that action by **showing the work before explaining it**.

## Factual relationship: correct the earlier shorthand

Superpowers+ is **not a Git fork or repository derivative** of `obra/superpowers`.

The factual relationship to preserve is:

- `obra/superpowers` is a respected external base workflow system Harley adopted and uses;
- Superpowers+ is a **plugin in Harley's Agent Asset Marketplace repository**;
- Superpowers+ does not have its own repository;
- there is no Git ancestry/branch/fork relationship between the two repositories;
- Superpowers+ adds first-party operating behaviour around the way Harley actually uses the base system.

Earlier Phase 8 wording that used `derivative`, `lineage` or an upstream-to-fork visual as shorthand must not be allowed to imply a Git relationship in later implementation.

The public story remains **adaptation under real use**: a strong base system was used seriously enough that specific operating needs became visible; separate first-party additions were then built around those needs. Handoff Gates remains the dominant worked example because it changes a consequential boundary: a producer declaring an artefact complete is not enough; the next worker must actually be able to continue without improvising.

## What was rejected in the integrated first pass

The first integrated Fold 2 proof used a deterministic graph/lineage image beside a conventional text column. Across the four responsive views it read as:

`heading + explanatory copy | framed project diagram`

That treatment is rejected.

The source idea was sound, but the visual was too small, too diagrammatic and too polite. It forced the copy to explain the evidence before the evidence had earned attention. It also failed to create the intended first change of visual gear after Fold 1's quiet mineral opening.

The deterministic graph asset is **out** as the Fold 2 lead visual.

The later production visual may use deterministic vector construction, but it should not return to a topology/lineage graph, Git-diff metaphor, screenshot or software-flowchart grammar.

## Exploration path — how the final visual language was found

### Workshop / calibration bench

The first serious metaphor treated `obra/superpowers` as a respected complete instrument/system and Superpowers+ as a separate set of purpose-built tooling developed through use. Handoff Gates could then behave like a specialist inspection fixture: the thing being handed off must pass a real readiness test before leaving the bench.

Relevant prior art included Framework's modular product photography, Todd McLellan's `Things Come Apart`, iFixit/specialist tool imagery and Pentagram's engineered-component work. The useful lesson was not `draw a workshop`; it was that premium engineering imagery can make **complete base system + separate purpose-built extension** legible without pretending the extension replaces the original.

The literal workshop was ultimately rejected because it imposed unnecessary scenery and risked generic precision-engineering theatre.

### Videogame / modpack

A videogame frame was tested adversarially: `obra/superpowers` as a respected AAA title and Superpowers+ as a collection of mods.

The relationship model was useful because a mod collection can remain separate from a good base game. The initial examples — higher framerate, ultrawide support, higher-resolution textures — were rejected because they framed Superpowers+ as polish. Handoff Gates is not polish; it changes an operating rule.

A `modded progression rules` version was more accurate, but the videogame metaphor still imposed too much decoding tax and risked generic gamer/futurist imagery.

### Tabletop / Advanced Ruleset

A tabletop RPG frame then improved the metaphor: the respected base system remained the base ruleset; Superpowers+ became an **Advanced Ruleset** rather than informal `house rules`. That mapped much better to governed progression, eligibility, shared operating constraints and explicit advancement conditions.

Turing Machine was especially useful prior art because its physical components make rules and verification visible: a state can exist, but progress depends on satisfying a criterion. Oink Games' component-design philosophy and Project L reinforced the idea that shape, scale and interaction can encode rules without requiring explanatory prose.

The literal tabletop treatment was also rejected. It risked niche/hobby framing and naturally drifted back toward cards, rulebooks and paper — a visual vocabulary already used to its limit in Patch.

### From metaphor to formal system

The workshop and ruleset passes exposed the shared useful abstraction: **a coherent modular system extended by compatible first-party components that change how progression through the system works**.

From there the room deliberately left literal metaphor behind.

Tetris was useful only as flavour: fit, modular rhythm, satisfying adjacency, pieces arriving into a coherent structure. Classic tetrominoes, falling-block composition and recognisable Tetris vocabulary are explicitly out.

A broader cultural/prior-art pass then supplied design DNA rather than themes:

- `Cube`: same structural unit, different state/identity through colour; useful, but no literal cubes/hatches/claustrophobic trap semantics;
- `TRON`: grid as a world with rules, crisp silhouette, colour as state and paths/seams that become meaningful; no black void, cyan/orange neon, glow or computer-world cosplay;
- `Lumines`: an assembled region is not automatically an accepted/actionable region;
- `Dr. Mario`, `Columns`, `Candy Crush` and `Bejeweled`: fast visual recognition of component families through colour; their cartoon/gem/candy aesthetics are not wanted;
- `Connect Four`: negative space can be a first-class state rather than leftover emptiness;
- `Pipe Mania / Pipe Dream`: local edge compatibility can determine whether a global route continues;
- railways, road maps and transit diagrams: continuation, junctions, switches and topology can matter more than literal geography;
- city-block grids: repeated modules can coexist with channels, streets, plazas and deliberate voids rather than filling every available cell;
- Windows 8 / Metro: flat rectilinear rhythm, different scales within one grid and colour carrying identity; UI tiles, icons and dashboard associations are an anti-reference;
- Sol LeWitt: a composition can look resolved first and then let the viewer unravel the rule that generated it;
- Wang tiles and Truchet tiles: compatibility can live at edges while a small component grammar creates complex global structure;
- the Smith variation on Truchet tiles is close enough to the emerging idea that the work should acknowledge and lean into that ancestry rather than pretending the resemblance is accidental;
- Penrose tilings: strong global coherence does not require obvious repetition;
- Josef Albers: colour is relational, supporting a same-world but different-batch distinction rather than a crude oppositional palette.

None of these references is a surface theme to copy. Their value was to expose formal behaviours that can be synthesised into an original Marketplace visual grammar.

## Settled visual concept: reverse-jigsaw negative-space system

The accepted concept is best understood as a **reverse jigsaw / modular channel system**, with more Tetris flavour than literal jigsaw — but without borrowing Tetris's pieces.

All components are square. No tile protrudes into another tile. The tessellation is created by **negative-space geometry cut into the squares**, not by tabs extending beyond their outer bounds.

The decisive idea is:

> **the negative space is the mechanism.**

The outer squares establish a shared modular world. The cut geometry determines whether neighbouring tiles genuinely connect.

### Mental model used to discover the shape rules

The room temporarily imagined each square as a 40-foot-wide, 40-foot-long, 40-foot-high solid block viewed from overhead. Circular channels had been cut vertically through it as though a giant cookie cutter removed the channel material. Entrance passages met those circular channels at tile edges. Some blocks had several passages, some had none, and some circular chambers only became complete when four exact blocks were placed together in the correct rotation.

The room then imagined a TRON-like rule: travel is possible only through the channels. If two neighbouring block passages do not align, there is a wall; no route exists. Superpowers+ blocks were imagined as separately hand-cast because Harley did not have the original moulds: compatible with the base grammar, but occasionally tight enough that the route is a `just about squeeze through sideways` fit rather than pristine factory alignment.

**That 3D fiction is not the visual.** It existed only to make the 2D negative-space choices exact and consequential.

The final treatment flattens all of that back into pure overhead 2D vector geometry. No concrete, caverns, perspective, travellers, game map, glow, tunnel lines or literal TRON world should appear.

## Settled tile grammar

### Core unit

Every component begins as a square tile.

- The outer silhouette remains square.
- No square protrudes into a neighbour.
- Variation comes from negative-space cuts within the tile and openings at its edges.
- Every tile edge should retain some meaningful flat connector surface; the current working heuristic is at least roughly 20% flat edge, subject to visual proof rather than blind numeric enforcement.

The square invariant provides the discipline. The internal cut geometry provides identity and behaviour.

### Circular negative-space language

Circular and curved cut geometry is an explicit choice.

A field of circles does not naturally tessellate the way a field of squares does. That tension is useful. The square grid wants regularity; circular subtraction introduces rhythm, softness, interruption and dependency.

A tile may have a very simple external fit — for example a 30% corner cut leaving a broad flat edge — while containing a much more intricate internal pattern of circular negative space. Edge compatibility is therefore not the whole visual story.

The internal negative space can create:

- circular chambers;
- partial circles;
- curved runs;
- apertures;
- branch-like cavities;
- larger forms that only become visible when several tiles cooperate.

One especially valuable second-read device is a complete circular chamber whose existence depends on four exact tiles meeting in the correct rotation. The viewer should be able to discover that rather than having it announced as a gimmick.

### Fit and edge compatibility

Two adjacent tiles only truly fit when the solid/flat portions of their neighbouring edges can meet without the solid of one tile overhanging into the other's negative-space channel.

This is the governing boundary rule.

The composition should contain a spectrum of joins:

- clean, comfortable base-system fits;
- close-tolerance fits;
- one or two deliberately imperfect `almost` fits where the circular cut on one side is slightly wider/narrower than its neighbour, leaving a small piece of solid edge intruding toward the channel;
- occasional non-fit or blocked alternatives where useful to reveal the rule.

The point is **not** that Harley added perfect new pieces to a perfect system. That would be false.

Superpowers+ additions are `scrappy fighters`: first-party interventions patched into a strong base framework at consequential points. They work. They upgrade the system at the spine. But they were not made from obra's original moulds and should not masquerade as factory-native pieces.

The visual should therefore preserve slight fit tension.

The target is **field-engineered precision, not bodge**. Tight, slightly awkward, still functional. A reader should feel `that just about fits, but it does fit`, not `that looks broken`.

## Provenance through colour

Colour carries authorship/provenance while shape carries compatibility.

### Superpowers base components

The base system uses one cooler, lower-saturation pastel/mineral family. It should feel calm, established and coherent — not greyed-out, obsolete or inferior.

### Superpowers+ components

The first-party additions use a compact family of stronger colours that vary harmoniously within the same palette of shades as each other and remain clearly distinct from the single calmer base-system family.

The intended effect is similar to a second production batch of compatible parts whose print/ink is brighter and whose internal registration is fractionally different.

The stronger colours do not mean `better`; they mean `another authored family, introduced later`.

The colour logic is therefore:

> **shape = compatibility**  
> **colour = authorship**

Hard oppositional palettes, generic SaaS gradients, neon TRON colour coding and `old grey / new bright blue` before/after language are rejected.

## Composition: a restrained path, not a packed field

Do not fill Fold 2 with wallpaper.

The premium authored character should come from **deliberately composing individual transparent assets in the available page space**. The preferred medium is SVG so colour remains controllable at composition time and the geometry stays crisp.

The intended structure is a restrained tiled path across the fold, with perhaps one or two branches. Mineral page background should remain visible as deliberate channels between and around groups of tiles.

Those background channels are not leftover whitespace. They provide:

- breathing room after the first fold;
- continuity with the site's cool mineral ground;
- visual route and rhythm;
- evidence that the modular field has been authored rather than procedurally wallpapered;
- premium negative-space control.

The composition should have enough pieces to let the rule emerge, but not so many that it becomes pattern for pattern's sake.

Superpowers+ pieces should concentrate around the meaningful route/boundary rather than being sprinkled decoratively across the field. Their placement should make it plausible, on second inspection, that continuation through the composition depends on them.

A piece or two may sit out of the settled path where that helps reveal the fitting rule, but no ambient `floating pieces` spectacle should be introduced merely because the assets permit it.

## Handoff Gates in the visual

Handoff Gates remains the dominant worked addition, but it should be **discoverable through the system's behaviour rather than announced by a giant labelled tile**.

The composition should make the important boundary readable:

- the base system establishes a coherent route;
- the critical transition contains stronger-coloured Superpowers+ pieces;
- those pieces make a route/continuation viable at a boundary where compatibility matters;
- at least one close-tolerance join should show that the intervention works without pretending to be pristine factory fit;
- the viewer can infer that `declared complete` is not enough — the next boundary must actually line up.

Labels such as `obra/superpowers`, `Superpowers+` and `Handoff Gates` may be supplied by the surrounding fold copy/composition. Avoid turning the tile system into a labelled dashboard. The visual should still contain enough logic that, with labels removed, a viewer could plausibly infer `base family + distinct compatible additions + important transition`.

## Authored assets and generative-tool boundary

Generative tools are explicitly in play for exploration. They may be used to discover:

- unexpected tile silhouettes/cut rhythms;
- circular negative-space patterns;
- pleasing adjacency ideas;
- colour-family relationships;
- candidate path/branch arrangements;
- ways to create delayed comprehension without literal diagrams.

They do **not** own final layout authority.

The preferred production model mirrors the accepted Patch treatment:

- create a small vocabulary of transparent SVG vector assets;
- regularise/redraw successful exploratory ideas into deliberate geometry rather than trusting arbitrary generated paths as precision;
- keep final colour controllable by the page composition where practical;
- compose those assets deliberately in the homepage rather than baking the entire fold into one generated image;
- make explicit breakpoint decisions instead of scaling/cropping one desktop composition down.

The premium authored flavour comes from deciding which component appears where, at what scale, in what rotation, with what neighbour, and with what amount of mineral negative space — not from asking a generative model to produce the final poster in one shot.

PNG may remain available for an asset whose appearance genuinely needs raster treatment, but the current preference is **SVG vector components** because this visual language is fundamentally shape-and-colour driven.

## Responsive composition contract

`desktop composition scaled down` is rejected.

The same asset vocabulary may be used at all sizes, but each breakpoint gets an authored composition.

A plausible direction, to be proved rather than copied mechanically:

- **wide:** broad restrained route across the available field, enough pieces to reveal internal circular rhythm, a branch or two, substantial mineral channels and a clear advanced intervention zone;
- **intermediate:** fewer pieces, stronger emphasis on the critical boundary, enough surrounding base system to keep provenance intelligible;
- **narrow:** a newly authored vertical/stepped route using only the pieces needed to communicate base → intervention → continuation; no attempt to miniaturise the wide arrangement.

Every stable state must remain deliberate without motion. Motion may later help reveal assembly or transition only if it improves the composition's meaning; comprehension must not depend on animation.

## Copy and density boundary

The visual carries most of Fold 2's expressive weight.

The working eyebrow/title territory remains `Agent Asset Marketplace · Superpowers+` and the working interpretive headline `A strong system, changed by using it.` remains viable, but exact public copy is **not locked by this visual-direction record**.

The existing long explanatory paragraph is not authority. Fold 2 should need far less prose once the visual is doing its job. The copy should close the inference, not narrate the entire relationship.

`Inspect the case study →` or an equivalent single deeper-read route continues to earn its place. Production provenance/debug captions such as `First-pass deterministic composition from inspected Marketplace source...` do not belong on the public homepage.

## Explicit anti-references

Do not turn this into:

- literal workshop/calibration-bench scenery;
- tabletop game components, rulebooks, cards or fantasy/RPG dressing;
- paper/manual/field-guide language already heavily used in Patch;
- videogame UI, mod menus or gamer imagery;
- Tetris tetrominoes or falling-block composition;
- literal jigsaw tabs;
- literal TRON grid/neon/computer-world treatment;
- Cube rooms/hatches;
- pipes, railway tracks, road-map lines or maze corridors;
- Windows/Metro UI tiles;
- generic topology diagrams, arrows or boxes;
- one generated hero image that dictates every responsive layout;
- decorative abstract pattern that never rewards the second look.

The references supplied physics and formal behaviour. The final work should look like itself.

## Acceptance test for the visual

The eventual Fold 2 proof should pass all of these before implementation planning treats the visual as mature:

1. **Two-second premium read:** before understanding the rule, the composition looks authored, controlled and at home on the portfolio.
2. **Second-read discovery:** within another few seconds, the viewer can notice that the negative spaces form meaningful connective geometry rather than arbitrary decoration.
3. **Family distinction:** the base Superpowers pieces and the stronger Superpowers+ pieces read as separate authored families without looking like opposing products.
4. **Compatibility without false perfection:** the SP+ pieces visibly belong to the same system but at least one consequential join carries `just about fits` tension.
5. **Boundary story:** the advanced pieces concentrate where continuation/fit matters, so Handoff Gates can be explained by the image rather than merely labelled on top of it.
6. **Emergent reward:** at least one larger circular/curved form rewards inspection by only becoming complete across several exact tiles/rotations.
7. **Negative-space authorship:** mineral channels and unfilled areas visibly improve the composition; the field does not become wallpaper.
8. **No false Git story:** nothing implies Superpowers+ is a repository fork of `obra/superpowers`.
9. **Responsive authorship:** wide, intermediate and narrow states are separately composed stable states, not crops/scales of one source image.
10. **No metaphor costume:** a viewer need not know about workshops, tabletop games, Tetris, TRON, Cube or the 40-foot-block thought experiment to understand the finished visual.
