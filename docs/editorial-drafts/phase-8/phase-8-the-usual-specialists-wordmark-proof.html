Font and production boundary

Chassis Black: purchased desktop licence, installed locally and requested only through local("Chassis Black"). This proof does not locate, copy, vendor, redistribute or commit the font binary.

Source Sans 3: existing repository-held OFL 1.1 WOFF2, weight 900. After geometry acceptance, Chassis may be converted to vector outlines for production while real semantic title text remains in the page. That conversion is not part of this proof.
