# Portfolio decision records

Each ADR preserves one dated design or architecture decision from the former single-file ledger. Records explain why a choice was made; the [active design policy](../../.agents/doctrine/portfolio-design-policy.md) and the current implementation govern present work. Accepted records describe decisions accepted at the time. Read later records and the active policy before treating an older decision as current.

Add one numbered ADR for a material new decision. State its context, decision, consequences, and when to reconsider it. Mark an earlier record superseded when the new decision replaces it.
