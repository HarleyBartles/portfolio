# Generated Image Custody Playbook

Use this playbook when a generated image is selected for Portfolio page iteration, reuse, or final production use.

## When

- A generated image moves from transient tool/chat output into repository-backed review or production custody.
- An accepted generated source is superseded or receives deterministic descendants.

## Required skills

- `asset-custody` for source custody and deterministic derivative handling.
- `verification-before-completion` before custody or provenance completion claims.

## Composition

1. Apply the general [asset playbook](asset.md) custody rules.
2. Custody the exact selected generated master before React, HTML, CSS, or durable wireframes reference its page-use derivative.
3. Record only evidenced generation metadata and the approved human brief while context is fresh.
4. Update the owning accepted/candidate inventory, receipt, provenance record, and deterministic lineage together.
5. Run focused custody/provenance checks before page use.

## Doctrine and contracts

- Exact generated bytes are the reproduction master; page derivatives are downstream artifacts.
- Unknown generation IDs, seeds, dates, prompts, or parent IDs remain explicit unknowns rather than reconstructed guesses.
- For The Usual Specialists, `src/client/assets/patch/the-usual-specialists/provenance/README.md` defines schema and evidence vocabulary.

## Local commands and paths

- Record original filename, repository source path or honest non-promoted state, SHA-256, dimensions, byte count, rights owner, and selection state.
- Distinguish `verbatim-recovered`, `normalized-from-approved-conversation`, `recovered-from-linear-record`, and `missing-from-retained-history` prompt/brief evidence honestly.
- For The Usual Specialists, `npm --prefix src/client run media:usual-specialists:check` validates custody, provenance links, deterministic lineage, and public derivative identity.

## Evidence contract

- Selected source master, generation receipt, normalized provenance, derivative receipt, selection state, and focused checks agree.
- Accepted deterministic descendants identify their `derivedFrom` lineage without inventing a new generation event.
- Superseded accepted imagery retains its historical custody and replacement relationship.

## Prohibited combinations

- Do not stand a generated asset up on a page before custody.
- Do not manufacture missing metadata or rewrite history to make a later selection look inevitable.
- Do not overwrite or silently crop/retouch/re-encode the retained reproduction master.
