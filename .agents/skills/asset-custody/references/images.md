# Image custody

Use this reference when adding, exporting, or reviewing images for the portfolio.

## Format

| Format | Use it when |
|---|---|
| AVIF | Best compression and quality. Use when the build pipeline supports it and the browser support is acceptable. |
| WebP | Broad browser support and smaller file size than JPEG or PNG. Use as the default safe modern format. |
| JPEG | The source is a photograph and WebP or AVIF cannot be produced. |
| PNG | The image needs transparency and the source cannot produce WebP or AVIF. |
| SVG | The image is a logo, icon, or illustration with flat colour and clear geometry. |

## Sizing

- Export at the largest size the design will display, not at the source resolution.
- For responsive images, provide 1x and 2x versions or a `srcset` range.
- Keep the display dimensions explicit in the consuming component or CSS.
- Do not let the browser downscale a large image when a smaller one exists.

## Alt text

- Write alt text as content, not as an afterthought.
- Describe the image and its purpose in the same sentence.
- Leave alt empty for decorative images only when the image adds no meaning.
- Do not use "image of" or "picture of" in the description.

## Loading

- Use `loading="eager"` for the largest above-the-fold image only.
- Use `loading="lazy"` for all other images.
- Add `decoding="async"` for non-critical images.

## Licensing and AI-generated images

- Record the source, license, and photographer or creator for every non-original image.
- If an image is generated by the `openai-image` MCP, keep the prompt, seed, and output path. Generated images may contain stylistic references, trademarks, or protected content. Review them for these risks before publishing. Do not commit the API key or any MCP configuration that contains it.
- Do not use stock photography unless it has been modified enough to match the site's voice and the license permits reuse.

## Checklist

- [ ] File format is the best supported by the build and the browser.
- [ ] Dimensions match the largest display size.
- [ ] Alt text is written and reviewed.
- [ ] Source and license are recorded.
- [ ] Fallback or placeholder exists.
