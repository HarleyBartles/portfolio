# Canonical composition index

Use canonical works as practice to inspect a story function, not as a prompt to
imitate a protected image, living artist, studio, or branded identity. Read the
linked authority entry for the underlying concept, then select the smallest useful
reference. The work names are anchors for analysis; the output must be a new,
story-specific direction.

## How to use the index

1. Name the story job and audience change.
2. Choose one row as the primary compositional family; add at most two supporting
   rows when their interaction is the beat.
3. Read the routed references and record the selected choice, rejected alternatives,
   and invariant that must survive translation.
4. Replace the canonical anchor with a new subject, viewpoint, field, and evidence
   boundary. Explain the function in plain language.

The authority surface at `assets/authority/CITATIONS.md` contains source links and
retrieval metadata. Operational references intentionally keep source links out of
their prose so attribution remains centralised and auditable.
