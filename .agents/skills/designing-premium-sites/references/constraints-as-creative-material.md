# Constraints as creative material

Limitations are fuel for improvisation. *The Shape of Design* shows that constraints hold the sand in the sandbox so we can play. Miles Davis created *Kind of Blue* by reducing the harmonic rules, which gave the musicians more room. *Resilient Web Design* shows that the web's constraints - unknown devices, uncertain networks, and partial feature support - are the very conditions that make it resilient. A premium portfolio turns constraints into creative material.

## Core lessons from the source

- Constraints force decisions. A tight scope, a limited palette, a single typeface, or a strict performance budget removes the option to add more and forces the designer to make what remains better.
- The web itself is a constraint. The web has no fixed canvas, unknown screen sizes, and partial browser support. A portfolio that treats these as features - using fluid grids and progressive enhancement - is more durable than one that pretends the web is a fixed sheet of paper.
- Self-imposed limits. Conceptual, structural, or tonal limits help us start work without waiting for a muse. They also prevent scope drift and keep the result coherent.
- Worst-idea-first. *The Shape of Design* suggests building momentum by considering the worst possible approach first. Every idea after looks better, and the process clarifies the real constraints.
- Yes, and. Good improvisation accepts contributions and builds on them. Constraints do not mean refusing input; they mean having a sandbox where input becomes useful.

## $10k vs $500

| $500 | $10k |
|---|---|
| No constraints; everything is possible | Uses constraints to force decisions |
| Grows by adding more | Refines by removing the unnecessary |
| Scope drifts | Scope is explicit and defended |
| Fights the web's nature | Uses the web's constraints as material |
