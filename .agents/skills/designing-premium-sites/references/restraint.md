# Restraint

More options, more animation, more colour, more fonts are not better. Restraint is the discipline to remove what does not serve the core message.

A premium feel often comes from fewer, better choices. If a typeface, an effect, or an interaction cannot be justified by the content, it is noise. The best portfolios feel inevitable because every remaining element has earned its place.

## $10k vs $500

| $500 | $10k |
|---|---|
| Adds every trendy effect | Keeps only what supports the core message |
| Uses many fonts, colours, and animations | Has a tight, ownable palette and motion vocabulary |
| Looks busy | Looks inevitable because every remaining element earned its place |
