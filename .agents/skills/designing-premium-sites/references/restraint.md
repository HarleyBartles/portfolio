# Restraint

Restraint is the discipline to remove what does not serve the core message. *The Shape of Design* ties this to the Shaker proverb: "Do not make something unless it is both necessary and useful; but if it is both, do not hesitate to make it beautiful." *Resilient Web Design* shows that the simplest parts of the web - one-way links, standard HTML - have outlasted the most elaborate attempts to replace them. A premium portfolio is not the sum of every effect it can show; it is the sum of every effect that earns its place.

## Core lessons from the source

- Necessity first. Before adding a colour, typeface, animation, or interaction, ask whether it is necessary and useful. If it is neither, it is clutter. If it is both, then make it beautiful.
- Fewer, better choices. Restraint often produces a more premium feel than abundance. A tight palette, a single type pairing, and a limited motion vocabulary make the site feel authored rather than assembled.
- Embrace limitations. *The Shape of Design* argues that constraints are not obstacles; they are fuel for improvisation. A strict scope, limited palette, or simple grid can produce better work than unlimited freedom.
- Avoid the car-alarm trap. The mockingbird imitates sounds it does not understand. A portfolio that copies every trend without understanding its purpose is the same. Only adopt patterns that serve the work's Why.
- Beauty is the residue of purpose. Beauty emerges when every remaining element has a reason. If an element cannot be justified, remove it.

## $10k vs $500

| $500 | $10k |
|---|---|
| Adds every trendy effect | Keeps only what supports the core message |
| Uses many fonts, colours, and animations | Has a tight, ownable palette and motion vocabulary |
| Looks busy | Looks inevitable because every remaining element earned its place |
| Treats limitations as deficits | Treats limitations as creative material |
