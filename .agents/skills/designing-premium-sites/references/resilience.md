# Resilience

A premium portfolio is built in layers. The base experience works without JavaScript, fancy fonts, or perfect networks. Enhancements are progressive, not assumptions.

This is the lesson of the web's history: simple, well-structured documents outlast the frameworks and devices that render them. Start with solid markup, legible text, and working links. Layer typography, layout, motion, and imagery on top of that foundation. If the top layers fail, the site must still communicate.

## $10k vs $500

| $500 | $10k |
|---|---|
| Works only with JavaScript enabled | Core content and navigation work without JavaScript |
| No fallbacks for custom fonts or features | System fonts and native HTML features are treated as the foundation |
| Assumes modern devices and fast networks | Degrades gracefully under poor conditions |
