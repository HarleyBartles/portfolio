# Assets

Images, icons, and fonts are chosen for quality, not quantity.

A generic hero image from a stock library undermines the claim that the work is personal. Assets should be appropriate to the format: modern image formats where they help, self-hosted or attribution-respecting fonts, and a consistent icon style. Favicons, Open Graph images, and other social assets should not be afterthoughts.

## $10k vs $500

| $500 | $10k |
|---|---|
| Generic or unoptimised images | Original or intentionally chosen images, appropriate format and size |
| Favicon and social preview missing | All meta assets and favicons in place |
| Mixed icon styles | A single, consistent icon set |
