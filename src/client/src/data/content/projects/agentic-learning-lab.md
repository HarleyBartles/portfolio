Agentic Learning Lab is a curriculum for teaching non-coders to work with agents effectively. It is a real teaching project and it is not finished.

The lab is built around a simple principle: the learner directs work, inspects it, questions it, and directs again. They do not become the manual implementation layer for the agent. Each exercise gives the learner a bounded problem, a safe disposable environment, and a clear recovery path so they can make mistakes without losing work.

The curriculum currently covers conversation versus workspace, project access, durable state, source-control save points, model versus harness, tools and skills, and later modules on context, provisioning, specialist sub-agents, and workflow design. The later modules are still being drafted. The earlier labs are usable and have been tested with real learners.

The repository is public: [github.com/HarleyBartles/agentic-learning-lab](https://github.com/HarleyBartles/agentic-learning-lab). It is incomplete but improving weekly. The public history is the proof.
