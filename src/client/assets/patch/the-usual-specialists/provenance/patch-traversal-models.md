## Original commission intent

Patch needed five reusable full-body cutouts that could follow Index through the giant-paper world while he continued the recruitment pitch. The set was not meant to be generic action poses: each pose had a narrative movement/gesture job while preserving one canonical Patch identity and the same pre-Index recruitment-folder state.

## Material changes from original intent

The final brief deliberately dropped the requirement for readable folder cover wording after user correction. The folder remained the same physical continuity object but its label was allowed to be blank/non-semantic at tiny traversal scale. Models 3–5 also used prior accepted Patch traversal outputs as lower-priority rendering continuity anchors in addition to the three canonical reference images.

## Accepted execution brief

Evidence status: `verbatim-recovered` from Linear’s stored approved generation brief.

Generate five separate single-image calls, each containing one complete Patch on genuine transparency with modest breathing room and no environment, paper surface, other character or manufactured occlusion. Preserve canonical teal hoodie/cream faceplate/two antennae/dark trousers/teal shoes/right-hip crossbody bag. Keep the same closed ochre/manila pre-Index folder incidental at Patch’s left side with no Index assent evidence. Pose families: ordinary following/talking; standing observational lean; high careful step over an implied document edge; almost-stationary palm-up conversational pause; rear-three-quarter continuation. Keep gesture restrained and readable at tiny scale.

## Iteration history

The five pose families were approved before generation with the explicit instruction to drive them as five separate calls rather than one multi-pose composition. Models 1–2 used the three canonical references directly; models 3–5 also used previously generated traversal images as rendering continuity anchors. The resulting five assets were then tested together in the document world rather than judged as isolated hero art.

## Acceptance decision

Accepted by Harley Bartles after all five were mounted at tiny traversal scale across the main document, blue carrier and graph-paper surfaces, including one cross-surface case and one deliberate page-layer occlusion. The user approved the assets while explicitly leaving final layout/choreography undecided.

## Known accepted limitations

- `patch-high-step` and `patch-pause` remain accepted historical material outside Portfolio source custody.
- No random seeds were supplied by the retained successful tool results.

Each PNG owns the complete Patch silhouette and carried folder state. React owns paper terrain, placement, scale, crop, overlap, occlusion, sequence and responsive choreography. The source files stay full body even when production composition shows only part of them.
